--- SKENARIO 1: Port Flapping (kayak sample V1) -------------
Di SW1 CLI:
  enable
  configure terminal
  interface fastEthernet0/1
  shutdown
  no shutdown
  shutdown
  no shutdown
  shutdown
  no shutdown
-> Cek Syslog di Server: 6 event %LINK + %LINEPROTO masuk
-> Copy semua, paste ke http://127.0.0.1:7860, Analyze

  (masukkan password SALAH 3x)
-> SW1 kirim %SEC_LOGIN-4-LOGIN_FAILED ke syslog server
